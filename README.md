# Alisha Android

**مصدر تطبيق Alisha لأندرويد | Android source of the Alisha app**

Alisha Android is the Kotlin / Jetpack Compose source code of the Alisha Android app — the Android companion of [Alisha](https://github.com/magen-gillan/alisha), the interactive Live2D AI companion web app.

Alisha Android هو كود تطبيق Alisha لأندرويد بلغة Kotlin وJetpack Compose — الرفيق الأندرويدي لتطبيق [Alisha](https://github.com/magen-gillan/alisha) الويب (رفيقة ذكاء اصطناعي تفاعلية بأفاتار Live2D).
